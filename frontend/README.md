# SmartAir Frontend

Premium environmental intelligence SaaS user interface built with React 18, TypeScript, Vite, Tailwind CSS, and Recharts.

## Features
- **Landing Page (`/`):** SaaS presentation, interactive methodology explainer, contaminant overview.
- **Dashboard (`/dashboard`):** Real-time monitoring metrics, 180-day AQI trend, pollutant breakdown, category distributions.
- **Forecast Studio (`/predictions`):** Select station and valid dates, review 7-day preceding observations, generate real ANN predictions.
- **Monitoring Network (`/stations`):** Searchable directory of 100+ stations with city filters and sensor availability.
- **Model Intelligence (`/model-insights`):** Layer blueprint, ablation table, loss convergence chart, leakage mitigation details.

## Setup & Running

```bash
cd frontend
npm install
npm run dev
```

App runs on `http://localhost:5173`.
